## ✨ Що таке ClipAIble?

ClipAIble використовує штучний інтелект для розумного витягування вмісту статей з будь-яких веб-сторінок — видаляє рекламу, навігацію, спливаючі вікна та зайві елементи. Потім експортує у вибраний формат:

- 📄 **PDF** — Красиве оформлення з можливістю налаштування
- 📚 **EPUB** — Підходить для Kindle, Kobo, Apple Books
- 📖 **FB2** — Підходить для PocketBook, FBReader
- 📝 **Markdown** — Звичайний текст для нотаток
- 🎧 **Аудіо** — Прослуховування з ШІ-озвучкою

Усі формати підтримують **переклад на 11 мов** — навіть переклад тексту на зображеннях!

## 🚀 Можливості

### 🤖 Витяг за допомогою ШІ
- **Два режими**: Автоматичний (без ШІ, швидкий), AI Selector (швидкий, повторно використовуваний)
- **Автоматичний режим**: Створення документів без ШІ — не потрібні API ключі, миттєве витягування
- **Підтримка кількох провайдерів**: OpenAI GPT (GPT-5.2, GPT-5.2-high, GPT-5.1), Google Gemini, Anthropic Claude, Grok, DeepSeek, OpenRouter
- **Витяг контенту з PDF** (v3.3.0): Витяг контенту з PDF файлів з використанням бібліотеки PDF.js
  - Експериментальна функція з багаторівневою системою класифікації
  - Витягує текст, зображення, структуру та метадані з PDF файлів
  - Підтримує як веб, так і локальні PDF файли
  - Обробляє багатоколоночні макети, таблиці, заголовки, списки, об'єднання між сторінками
  - Примітка: Функція експериментальна і може мати обмеження зі складними PDF (скановані PDF, захищені паролем PDF)
- **Підтримка відео**: Витяг субтитрів з відео YouTube/Vimeo та перетворення в статті (v3.0.0)
  - Кілька методів витягу з резервними варіантами
  - Пріоритет: ручні субтитри > автоматично згенеровані > перекладені
  - Обробка ШІ: видаляє часові мітки, об'єднує абзаци, виправляє помилки
  - Резервний варіант транскрибації аудіо за відсутності субтитрів
- **Розумне визначення**: Знаходить основний вміст статті, автоматично видаляє зайве
- **Розширені стратегії резервування**: 6 різних стратегій для надійного витягу вмісту
- **Збереження структури**: Заголовки, зображення, блоки коду, таблиці, виноски
- **Кешування селекторів**: Незалежні налаштування для використання та ввімкнення кешу

### 🎧 Експорт в аудіо
- **6 провайдерів синтезу мовлення**: OpenAI TTS, ElevenLabs, Google Gemini 2.5 TTS, Qwen3-TTS-Flash, Respeecher, Piper TTS (офлайн)
- **Регулювання швидкості**: від 0.25x до 4.0x (тільки OpenAI/ElevenLabs; Google/Qwen/Respeecher/Piper TTS (офлайн) використовують фіксовану швидкість)
- **Підтримка форматів**: MP3 (OpenAI/ElevenLabs) або WAV (Google/Qwen/Respeecher/Piper TTS (офлайн))
- **Багатомовна вимова**: Коректна вимова для кожної мови
- **Підтримка української мови**: Спеціальні українські голоси через Respeecher
- **Piper TTS (офлайн)**: Працює повністю офлайн, не потрібно API ключів, кілька голосів на 8 мовах (англійська, російська, німецька, французька, іспанська, італійська, португальська, китайська)
- **Розумне очищення тексту**: ШІ видаляє URL, код та неречевий вміст
- **Особливості провайдерів**: Вибір моделі, опції формату та розширені налаштування доступні для кожного провайдера

### 🌍 Переклад
- **11 мов**: EN, RU, UA, DE, FR, ES, IT, PT, ZH, JA, KO
- **Розумне визначення**: Пропускає переклад, якщо стаття вже цільовою мовою
- **Переклад зображень**: Перекладає текст на зображеннях (через Gemini)
- **Адаптовані метадані**: Дати та підписи адаптуються до вибраної мови

### 🎨 Налаштування PDF
- **4 передустановки**: Темна, Світла, Сепія, Високий контраст
- **Налаштовувані кольори**: Фон, текст, заголовки, посилання
- **11 шрифтів**: За замовчуванням (Segoe UI), Arial, Georgia, Times New Roman, Verdana, Tahoma, Trebuchet MS, Palatino Linotype, Garamond, Courier New, Comic Sans MS
- **Розмір шрифту**: Налаштовуваний (за замовчуванням: 31px)
- **Режими сторінок**: Одна безперервна сторінка або багатосторінковий формат A4


### ⚡ Розумні функції
- **Витяг контенту з PDF** (v3.3.0): Витяг контенту з PDF файлів та перетворення в статті
  - Використовує бібліотеку PDF.js для парсингу в offscreen document
  - Багаторівнева система класифікації для точного витягу
  - Підтримує як веб, так і локальні PDF файли
  - Повна інтеграція в пайплайн: переклад, зміст, резюме, всі формати експорту
  - Примітка: Експериментальна функція, може мати обмеження зі складними PDF
- **Підтримка відео**: Витяг субтитрів з відео YouTube/Vimeo та перетворення в статті (v3.0.0)
  - Прямий витяг субтитрів (API ключі від YouTube/Vimeo не потрібні)
  - Обробка ШІ: видаляє часові мітки, об'єднує абзаци, виправляє помилки
  - Повна інтеграція в пайплайн: переклад, зміст, резюме, всі формати експорту
- **Генерація саммарі**: Створення детальних ШІ-саммарі будь-якої статті або відео
  - Натисніть кнопку **"Створити саммарі"** для створення детального саммарі
  - Працює зі звичайними статтями та відео YouTube/Vimeo
  - Продовжує генерацію навіть при закритому попапі (працює у фоні)
  - Копіювання в буфер обміну або завантаження як файл Markdown
  - Розгортається/згортається відображення з відформатованим текстом
  - Детальні саммарі з ключовими ідеями, концепціями, прикладами та висновками
- **Резюме (TL;DR)**: ШІ-написане коротке резюме з 2-4 речень, включене в документи
  - Опціональна функція: увімкніть у налаштуваннях для додавання короткого резюме в PDF/EPUB/FB2/Markdown
  - З'являється на початку експортованих документів
  - Відрізняється від детального саммарі (це короткий огляд)
- **Офлайн режим**: Кешування селекторів — ШІ не потрібен для повторних відвідувань сайтів
  - Незалежні налаштування: використання кешованих селекторів та ввімкнення кешування окремо
  - Автоматична інвалідація при невдалому витягу
  - Ручне управління кешем за доменами
- **Статистика**: Відстеження кількості збережень, перегляд історії
- **Зміст**: Автоматично генерується з заголовків

## ⚠️ Відомі обмеження

### Формати файлів
- **Формат WAV** (Google/Qwen/Respeecher): Файли можуть бути дуже великими (10-50MB+ для довгих статей). Формат MP3 (OpenAI/ElevenLabs) забезпечує менший розмір файлів.
- **Ліміти символів на запит**: 
  - OpenAI TTS: 4096 символів
  - ElevenLabs: 5000 символів
  - Google Gemini 2.5 TTS: 24000 символів
  - Qwen TTS: 600 символів
  - Respeecher TTS: 450 символів
  - Текст автоматично розбивається за межами речень/слів

### Технічні обмеження
- **Вимога keep-alive**: Chrome MV3 вимагає інтервал keep-alive не менше 1 хвилини. Довгі задачі обробки можуть зайняти кілька хвилин. Розширення використовує уніфікований механізм keep-alive (alarm кожну 1 хвилину) для запобігання зупинки service worker.
- **CORS для зображень**: Деякі зображення можуть не завантажитися, якщо сайт блокує cross-origin запити. Розширення пропустить ці зображення.
- **Скасування не миттєве**: Скасування може зайняти кілька секунд для повної зупинки всіх фонових процесів.
- **Відновлення Service Worker**: Операції автоматично відновлюються після перезапуску service worker, якщо стан свіжий (< 1 хвилини). Перезавантаження розширення завжди скидає стан.
- **Обмеження витягу з PDF** (v3.3.0): 
  - Скановані PDF (без текстового шару) не підтримуються — OCR поки недоступний
  - Захищені паролем PDF повинні бути розблоковані перед витягом
  - Дуже великі PDF (>100MB) можуть не працювати через обмеження пам'яті
  - Складні макети (багатоколоночні, таблиці) витягуються, але можуть потребувати ручної перевірки

### Сумісність з браузерами
- **Chrome/Edge/Brave/Arc**: Повністю підтримується
- **Firefox**: Не підтримується (використовує інший API розширень)
- **Safari**: Не підтримується (використовує інший API розширень)

## 🔑 Отримання API ключів

> **💡 Порада**: Ви можете використовувати ClipAIble без API ключів! Автоматичний режим працює миттєво, використовуючи локальні алгоритми. API ключі потрібні лише для функцій з ШІ (переклад, генерація резюме, режим AI Selector).
> 
> **💡 Нове в v3.2.0**: Piper TTS (офлайн) - Генеруйте аудіо повністю офлайн з 50+ голосами на 9 мовах, API ключі не потрібні!
> 
> **💡 Виправлено в v3.2.1**: UI попапа оновлюється коректно після генерації аудіо, перемикання голосів працює правильно для офлайн TTS.
> 
> **💡 Нове в v3.3.0**: Витяг контенту з PDF - Додано експериментальну підтримку витягу контенту з PDF файлів. Попереднє: Інтеграція провайдера DeepSeek, оптимізації продуктивності, виправлення перешкод Google Translate.

### OpenAI (моделі GPT + Аудіо)

1. Перейдіть на [platform.openai.com](https://platform.openai.com/)
2. Зареєструйтеся або увійдіть
3. Перейдіть до **API Keys** (ліве меню) або безпосередньо на [platform.openai.com/api-keys](https://platform.openai.com/api-keys)
4. Натисніть **"Create new secret key"**
5. Скопіюйте ключ (починається з `sk-...`)
6. Додайте оплату в **Settings → Billing** (потрібно для використання API)

> **Примітка:** Ключ OpenAI потрібен для експорту в аудіо (TTS). Інші формати працюють з будь-яким провайдером.

### Google Gemini

1. Перейдіть на [Google AI Studio](https://aistudio.google.com/)
2. Увійдіть з обліковим записом Google
3. Натисніть **"Get API key"** або перейдіть на [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
4. Натисніть **"Create API key"**
5. Скопіюйте ключ (починається з `AIza...`)

> **Порада:** Gemini також включає функцію перекладу тексту на зображеннях та Google Gemini 2.5 TTS (30 голосів). Для TTS можна використовувати той самий ключ Gemini API або встановити окремий ключ Google TTS API. Потрібно ввімкнення Generative Language API в Google Cloud Console.

### Anthropic Claude

1. Перейдіть на [console.anthropic.com](https://console.anthropic.com/)
2. Зареєструйтеся або увійдіть
3. Перейдіть до **API Keys**
4. Натисніть **"Create Key"**
5. Скопіюйте ключ (починається з `sk-ant-...`)
6. Додайте кредити в **Plans & Billing**

### DeepSeek

1. Перейдіть на [platform.deepseek.com](https://platform.deepseek.com/)
2. Зареєструйтеся або увійдіть
3. Перейдіть до **API Keys** або перейдіть на [platform.deepseek.com/api_keys](https://platform.deepseek.com/api_keys)
4. Натисніть **"Create API key"**
5. Скопіюйте ключ (починається з `sk-...`)

> **Примітка:** DeepSeek надає моделі DeepSeek-V3.2: `deepseek-chat` (режим без reasoning) та `deepseek-reasoner` (режим з reasoning). API сумісний з форматом OpenAI.

### ElevenLabs (Аудіо)

1. Перейдіть на [ElevenLabs](https://elevenlabs.io/)
2. Зареєструйтеся або увійдіть
3. Перейдіть до **Profile** → **API Keys**
4. Створіть API ключ
5. Скопіюйте ключ

> **Примітка:** ElevenLabs надає 9 преміум голосів з високоякісним TTS. Підтримує регулювання швидкості (0.25-4.0x) та вибір формату (MP3 висока якість за замовчуванням: mp3_44100_192). Моделі: Multilingual v2, v3 (за замовчуванням), Turbo v2.5. Доступні розширені налаштування голосу (stability, similarity, style, speaker boost).

### Google Gemini 2.5 TTS (Аудіо)

1. Перейдіть на [Google AI Studio](https://aistudio.google.com/)
2. Увійдіть з обліковим записом Google
3. Натисніть **"Get API key"** або перейдіть на [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
4. Натисніть **"Create API key"**
5. Скопіюйте ключ (починається з `AIza...`)
6. Ввімкніть **Generative Language API** в [Google Cloud Console](https://console.cloud.google.com/)
7. (Опціонально) Ввімкніть оплату, якщо потрібно для вашої моделі

> **Примітка:** Google Gemini 2.5 TTS надає 30 голосів. Можна використовувати той самий ключ Gemini API або встановити окремий ключ Google TTS API. Фіксований формат WAV на 24kHz. Моделі: `gemini-2.5-pro-preview-tts` (основна) або `gemini-2.5-flash-preview-tts` (швидша).

### Qwen3-TTS-Flash (Аудіо)

1. Перейдіть на [Alibaba Cloud Model Studio](https://dashscope-intl.console.aliyun.com/)
2. Зареєструйтеся або увійдіть
3. Перейдіть до **API Keys** або **Model Studio**
4. Створіть API ключ
5. Скопіюйте ключ (починається з `sk-...`)

> **Примітка:** Qwen3-TTS-Flash надає 49 голосів, включаючи спеціальний російський голос (Alek). Фіксований формат WAV на 24kHz.

### Respeecher (Аудіо - Англійська та Українська)

1. Перейдіть на [Respeecher Space](https://space.respeecher.com/)
2. Зареєструйтеся або увійдіть
3. Перейдіть до **API Keys**
4. Створіть API ключ
5. Скопіюйте ключ

> **Примітка:** Respeecher підтримує англійську та українську мови зі спеціальними українськими голосами. Фіксований формат WAV на 22.05kHz.

### Офлайн режим

ClipAIble кешує згенеровані ШІ селектори за доменом:
- **Другий візит = миттєво** — без виклику API
- **Автоматична інвалідація** — кеш очищається при невдалому витягуванні
- **Ручне управління** — можливість видалення окремих доменів
- **Незалежні налаштування**:
  - **Використовувати закешовані селектори**: Пропустити аналіз сторінки, якщо кеш існує (швидше)
  - **Увімкнути кешування**: Зберігати нові селектори в кеш після витягування
  - Обидві налаштування працюють незалежно для гнучкого управління

## 🔧 Вирішення проблем

| Проблема | Рішення |
|----------|---------|
| Порожній вміст | Спробуйте режим **AI Selector** |
| Невірний API ключ | Перевірте формат ключа (sk-..., AIza..., sk-ant-...) |
| Відсутні зображення | Деякі сайти блокують cross-origin; маленькі зображення автоматично фільтруються |
| Повільне аудіо | Довгі статті розбиваються на частини; слідкуйте за індикатором прогресу |
| Саммарі не генерується | Перевірте API ключ, переконайтеся що вміст сторінки завантажено, спробуйте знову |
| Таймаут генерації саммарі | Дуже довгі статті можуть зайняти до 45 хвилин; зачекайте або спробуйте з коротшим вмістом |
| Витяг з PDF не працює | Перевірте, чи не захищений PDF паролем (спочатку розблокують) або чи не є він сканованим (OCR поки не підтримується). Спробуйте з простішими PDF спочатку. |
| Контент з PDF неповний | Складні макети (багатоколоночні, таблиці) можуть потребувати ручної перевірки. Функція експериментальна. |

## 📋 Дозволи

ClipAIble вимагає наступні дозволи для функціонування. Всі дозволи використовуються лише для зазначених цілей:

| Дозвіл | Чому |
|--------|------|
| `activeTab` | Читання статті з поточної вкладки при натисканні на іконку розширення або використанні контекстного меню. Розширення отримує доступ лише до вкладки, яку ви зараз переглядаєте. |
| `storage` | Збереження ваших налаштувань (API ключі, стилі, вибір мови) та статистики локально у вашому браузері. Ваші дані ніколи не покидають ваш пристрій. |
| `scripting` | Впровадження скрипта витягування вмісту на веб-сторінки. Цей скрипт знаходить та витягує вміст статті (текст, зображення, заголовки) з DOM сторінки. |
| `downloads` | Збереження згенерованих файлів (PDF, EPUB, FB2, Markdown, Аудіо) на ваш комп'ютер. Без цього дозволу розширення не може завантажувати файли. |
| `debugger` | **Тільки для генерації PDF** - Використовує вбудовану функцію Chrome print-to-PDF для генерації високоякісних PDF з правильним макетом сторінки та стилізацією. Debugger підключається лише під час генерації PDF та одразу відключається після завершення. Це єдиний спосіб генерації PDF з користувацькою стилізацією в розширеннях Chrome. |
| `alarms` | Підтримка фонового service worker у активному стані під час довгих операцій (великі статті, переклад). Chrome Manifest V3 призупиняє service workers після 30 секунд, але обробка статей може зайняти кілька хвилин. Використовує уніфікований механізм keep-alive (alarm кожну 1 хвилину + збереження стану кожні 2 секунди) згідно з правилами MV3. |
| `contextMenus` | Додавання опцій "Зберегти з ClipAIble" (PDF/EPUB/FB2/MD/Аудіо) до контекстного меню на веб-сторінках. |
| `notifications` | Показ сповіщень на робочому столі при використанні функції "Зберегти" з контекстного меню. Сповіщає про помилки (наприклад, відсутній API ключ). |
| `unlimitedStorage` | Зберігання кешу селекторів та тимчасових даних друку локально. Це дозволяє швидші повторні витягування без повторного виклику ШІ (офлайн режим). |

### Дозволи хоста

| Дозвіл | Чому |
|--------|------|
| `<all_urls>` | Витягування вмісту з будь-якого веб-сайту, який ви відвідуєте. Розширення потребує: 1) Читати HTML сторінки для пошуку вмісту статті, 2) Завантажувати зображення, вбудовані в статті, 3) Робити API виклики до провайдерів ШІ/TTS (OpenAI, Google, Anthropic, ElevenLabs, Qwen, Respeecher). **Примітка безпеки:** Всі API ключі шифруються за допомогою AES-256-GCM та зберігаються лише локально. Ключі ніколи не експортуються та не передаються на будь-який сервер, окрім провайдерів ШІ, яких ви налаштували.

2. Створіть гілку функції: `git checkout -b feature/cool-thing`
3. Коміт: `git commit -m 'Add cool thing'`
4. Пуш: `git push origin feature/cool-thing`
5. Відкрийте Pull Request

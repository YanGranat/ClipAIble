# ClipAIble

Розширення для витягу статей за допомогою ШІ. Працює на будь-якому сайті.

## Що воно робить

ClipAIble витягує вміст статей із веб-сторінок і перетворює в різні формати:
- PDF документи
- EPUB файли
- FB2 файли
- Markdown текст
- Аудіо файли

**Особливі можливості:**
- **Підтримка YouTube/Vimeo**: Витягує субтитри відео та створює статті з них
- **Обробка PDF**: Працює з онлайн PDF та локальними PDF файлами
- **Переклад контенту**: Переклад статей на 11 мов
- **Переклад зображень**: Переклад тексту на зображеннях за допомогою ШІ
- **Генерація TLDR**: Створює короткі резюме всередині документів
- **Панель summary**: Показує резюме статей у popup після обробки

## Встановлення

Встановіть із [Chrome Web Store](https://chromewebstore.google.com/detail/clipaible/khcklmlkddcaflolc).

## Як використовувати

1. Натисніть на іконку ClipAIble у панелі інструментів браузера
2. Відкрийте будь-яку статтю, відео на YouTube або PDF
3. Виберіть потрібний формат (PDF, EPUB, FB2, Markdown або Audio)
4. Натисніть зберегти

**Альтернативні способи збереження:**
- Клацніть правою кнопкою миші на будь-якій веб-сторінці та використовуйте опції контекстного меню

**Для локальних PDF файлів**: У режимах ШІ вам буде запропоновано вибрати PDF файл через обмеження браузера.

## Налаштування

### Режими витягу

- **AI Selector**: Рекомендований режим для більшості сайтів. Використовує ШІ для пошуку вмісту статті.
- **Automatic**: Базовий режим, який працює без API ключів.
- **AI Extractor**: Альтернативний режим із ШІ (не рекомендується для регулярного використання).

### Функції продуктивності

- **Кешування селекторів**: Прискорює обробку раніше відвіданих сайтів шляхом повторного використання селекторів, вивчених ШІ

### Формати виводу

- **PDF**: Створює відформатовані документи з 4 готовими стилями (Темний, Світлий, Сепія, Високий контраст) та настроюваними шрифтами/кольорами
- **EPUB**: Створює структуровані електронні книги для читалок на кшталт Kindle
- **FB2**: Створює структуровані електронні книги для PocketBook та інших читалок
- **Markdown**: Зберігає структуру статті із заголовками та списками
- **Audio**: Перетворює текст на мову з використанням 6 різних TTS сервісів

### Переклад

Вміст можна перекласти на: англійську, російську, українську, німецьку, французьку, іспанську, італійську, португальську, китайську, японську, корейську.

### Аудіо

Аудіо можна генерувати за допомогою різних TTS провайдерів:
- OpenAI TTS
- ElevenLabs
- Google Gemini
- Qwen
- Respeecher (тільки англійська та українська)
- Piper (офлайн, API ключі не потрібні)

## API ключі (опціонально)

Для функцій ШІ можна додати API ключі від цих провайдерів:

### OpenAI
Отримайте ключ на [platform.openai.com/api-keys](https://platform.openai.com/api-keys)

### Google Gemini
Отримайте ключ на [aistudio.google.com/apikey](https://aistudio.google.com/apikey)

Для TTS увімкніть [Generative Language API](https://console.cloud.google.com/apis/library/generativelanguage.googleapis.com) у Google Cloud Console

### Anthropic Claude
Отримайте ключ на [console.anthropic.com](https://console.anthropic.com/)

### DeepSeek
Отримайте ключ на [platform.deepseek.com/api_keys](https://platform.deepseek.com/api_keys)

### ElevenLabs
Отримайте ключ на [elevenlabs.io](https://elevenlabs.io/)

### Qwen
Отримайте ключ на [alibaba cloud dashscope](https://dashscope-intl.console.aliyun.com/)

### Respeecher
Отримайте ключ на [space.respeecher.com](https://space.respeecher.com/)

## Додаткові можливості

- **Статистика**: Відстежуйте збережені статті з історією та місячними лічильниками
- **Імпорт/експорт налаштувань**: Резервне копіювання та відновлення ваших уподобань
- **Інтерфейс на 11 мовах**: Переключення між мовами без перезапуску
- **Безпечне зберігання**: API ключі шифруються перед збереженням

## Дозволи

Розширенню потрібні ці дозволи для роботи:
- Читати веб-сторінки, які ви відвідуєте
- Зберігати файли на ваш комп'ютер
- Робити API виклики до провайдерів ШІ (тільки коли ви використовуєте ці функції)

**Безпека**: Всі API ключі шифруються перед збереженням у браузері.

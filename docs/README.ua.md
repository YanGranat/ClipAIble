# ClipAIble

Збереження вебстатей у PDF, EPUB, FB2, Markdown або аудіо.

[Chrome Web Store](https://chromewebstore.google.com/detail/clipaible/khcklmlkddcaflkoonkkefjhdldcfolc)

## Використання

1. Відкрийте статтю, підтримуване відео або PDF.
2. Натисніть значок ClipAIble на панелі інструментів Chrome.
3. Виберіть формат і режим отримання вмісту.
4. Натисніть **Зберегти**.

Збереження також доступне в контекстному меню сторінки. Для локальних PDF дозвольте доступ до файлів у налаштуваннях розширення Chrome або виберіть відповідний файл на запит. Якщо потрібен вибір файлу, залиште popup розширення відкритим.

Для вебстатей режим **Автоматичний** використовує локальні евристики й доступні селектори з кешу. **AI Selector** запитує в AI-сервісу CSS-селектори, а потім отримує відповідний вміст сторінки. **AI Extract** доручає сервісу структурувати вміст. Для PDF автоматичний режим отримує текстовий шар, а AI-режими обробляють відтворені сторінки.

Щоб експортувати відео з YouTube і Vimeo, потрібні субтитри й ключ API постачальника ШІ, вибраного для статей. Це стосується й режиму **Автоматичний**.

У налаштуваннях доступні переклад тексту та зображень, стилі документа й зміст. У вікні розширення можна створити стислий виклад або ключові тези. Для озвучення можна використовувати налаштований сервіс або завантажити модель Piper чи Supertonic і синтезувати мовлення на комп’ютері.

Додайте ключі API для вибраних функцій ШІ та озвучення. Резервна копія JSON містить налаштування й власні промпти. До неї можна додати статистику, історію та кеш селекторів. Ключі API до копії не входять. Під час імпорту можна додати відсутні записи історії й правила для нових сайтів або замінити вибрані розділи даними з копії. Докладніше в розділі [Резервні копії налаштувань](../README.md#back-up-settings).

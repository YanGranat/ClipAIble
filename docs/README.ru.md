## ✨ Что такое ClipAIble?

ClipAIble использует искусственный интеллект для интеллектуального извлечения содержимого статей с любых веб-страниц — удаляет рекламу, навигацию, всплывающие окна и лишние элементы. Затем экспортирует в выбранный формат:

- 📄 **PDF** — Красивое оформление с возможностью настройки
- 📚 **EPUB** — Подходит для Kindle, Kobo, Apple Books
- 📖 **FB2** — Подходит для PocketBook, FBReader
- 📝 **Markdown** — Обычный текст для заметок
- 🎧 **Аудио** — Прослушивание с ИИ-озвучкой

Все форматы поддерживают **перевод на 11 языков** — даже перевод текста на изображениях!

## 🚀 Возможности

### 🤖 Извлечение с помощью ИИ
- **Два режима**: Автоматический (без ИИ, быстрый), AI Selector (быстрый, повторно используемый)
- **Автоматический режим**: Создание документов без ИИ — не требуется API ключей, мгновенное извлечение
- **Поддержка нескольких провайдеров**: OpenAI GPT (GPT-5.2, GPT-5.2-high, GPT-5.1), Google Gemini, Anthropic Claude, Grok, DeepSeek, OpenRouter
- **Извлечение контента из PDF** (v3.3.0): Извлечение контента из PDF файлов с использованием библиотеки PDF.js
  - Экспериментальная функция с многоуровневой системой классификации
  - Извлекает текст, изображения, структуру и метаданные из PDF файлов
  - Поддерживает как веб, так и локальные PDF файлы
  - Обрабатывает многоколоночные макеты, таблицы, заголовки, списки, объединение между страницами
  - Примечание: Функция экспериментальная и может иметь ограничения со сложными PDF (сканированные PDF, защищённые паролем PDF)
- **Поддержка видео**: Извлечение субтитров из видео YouTube/Vimeo и преобразование в статьи (v3.0.0)
  - Несколько методов извлечения с резервными вариантами
  - Приоритет: ручные субтитры > автоматически сгенерированные > переведённые
  - Обработка ИИ: удаляет временные метки, объединяет абзацы, исправляет ошибки
  - Резервный вариант транскрибации аудио при отсутствии субтитров
- **Умное определение**: Находит основное содержимое статьи, автоматически удаляет лишнее
- **Сохранение структуры**: Заголовки, изображения, блоки кода, таблицы

### 🎧 Экспорт в аудио
- **6 провайдеров синтеза речи**: OpenAI TTS, ElevenLabs, Google Gemini 2.5 TTS, Qwen3-TTS-Flash, Respeecher, Piper TTS (офлайн)
- **Регулировка скорости**: от 0.25x до 4.0x (только OpenAI/ElevenLabs; Google/Qwen/Respeecher/Piper TTS (офлайн) используют фиксированную скорость)
- **Поддержка форматов**: MP3 (OpenAI/ElevenLabs) или WAV (Google/Qwen/Respeecher/Piper TTS (офлайн))
- **Многоязычное произношение**: Корректное произношение для каждого языка
- **Поддержка украинского языка**: Специальные украинские голоса через Respeecher
- **Piper TTS (офлайн)**: Работает полностью офлайн, не требуется API ключей, несколько голосов на 8 языках (английский, русский, немецкий, французский, испанский, итальянский, португальский, китайский)
- **Умная очистка текста**: ИИ удаляет URL, код и неречевое содержимое
- **Особенности провайдеров**: Выбор модели, опции формата и расширенные настройки доступны для каждого провайдера

### 🌍 Перевод
- **11 языков**: EN, RU, UA, DE, FR, ES, IT, PT, ZH, JA, KO
- **Умное определение**: Пропускает перевод, если статья уже на целевом языке
- **Перевод изображений**: Переводит текст на изображениях (через Gemini)
- **Адаптированные метаданные**: Даты и подписи адаптируются к выбранному языку

### 🎨 Настройка PDF
- **4 предустановки**: Тёмная, Светлая, Сепия, Высокий контраст
- **Настраиваемые цвета**: Фон, текст, заголовки, ссылки
- **11 шрифтов**: По умолчанию (Segoe UI), Arial, Georgia, Times New Roman, Verdana, Tahoma, Trebuchet MS, Palatino Linotype, Garamond, Courier New, Comic Sans MS
- **Размер шрифта**: Настраиваемый (по умолчанию: 31px)
- **Режимы страниц**: Одна непрерывная страница или многостраничный формат A4


### ⚡ Умные функции
- **Извлечение контента из PDF** (v3.3.0): Извлечение контента из PDF файлов и преобразование в статьи
  - Использует библиотеку PDF.js для парсинга в offscreen document
  - Многоуровневая система классификации для точного извлечения
  - Поддерживает как веб, так и локальные PDF файлы
  - Полная интеграция в пайплайн: перевод, оглавление, резюме, все форматы экспорта
  - Примечание: Экспериментальная функция, может иметь ограничения со сложными PDF
- **Поддержка видео**: Извлечение субтитров из видео YouTube/Vimeo и преобразование в статьи (v3.0.0)
  - Прямое извлечение субтитров (API ключи от YouTube/Vimeo не требуются)
  - Обработка ИИ: удаляет временные метки, объединяет абзацы, исправляет ошибки
  - Полная интеграция в пайплайн: перевод, оглавление, резюме, все форматы экспорта
- **Генерация саммари**: Создание подробных ИИ-саммари любой статьи или видео
  - Нажмите кнопку **"Создать саммари"** для создания подробного саммари
  - Работает с обычными статьями и видео YouTube/Vimeo
  - Продолжает генерацию даже при закрытом попапе (работает в фоне)
  - Копирование в буфер обмена или скачивание как файл Markdown
  - Раскрывающийся/сворачивающийся отображение с форматированным текстом
  - Подробные саммари с ключевыми идеями, концепциями, примерами и выводами
- **Резюме (TL;DR)**: ИИ-написанное краткое резюме из 2-4 предложений, включённое в документы
  - Опциональная функция: включите в настройках для добавления краткого резюме в PDF/EPUB/FB2/Markdown
  - Появляется в начале экспортированных документов
  - Отличается от подробного саммари (это краткий обзор)
- **Офлайн режим**: Кэширование селекторов — ИИ не требуется для повторных посещений сайтов
  - Независимые настройки: использование кэшированных селекторов и включение кэширования отдельно
  - Автоматическая инвалидация при неудачном извлечении
  - Ручное управление кэшем по доменам
- **Статистика**: Отслеживание количества сохранений, просмотр истории
- **Оглавление**: Автоматически генерируется из заголовков
- **Контекстное меню**: Правый клик → "Сохранить статью как PDF/EPUB/FB2/Markdown/Аудио"
- **Отмена в любой момент**: Остановка обработки одним кликом
- **Импорт/экспорт настроек**: Резервное копирование и восстановление всех настроек (API ключи исключены из соображений безопасности)

### 🔒 Безопасность
- **API ключи зашифрованы** с помощью AES-256-GCM (OpenAI, Claude, Gemini, Grok, DeepSeek, OpenRouter, ElevenLabs, Qwen, Respeecher)
- **Ключи никогда не экспортируются** — исключены из резервной копии настроек
- **Все данные хранятся локально** — ничего не отправляется третьим лицам

## ⚠️ Известные ограничения

### Форматы файлов
- **Формат WAV** (Google/Qwen/Respeecher): Файлы могут быть очень большими для длинных статей. Формат MP3 (OpenAI/ElevenLabs) обеспечивает меньший размер файлов.
- **Разбиение текста**: Длинные статьи автоматически разбиваются по границам предложений/слов
- **Ограничения извлечения из PDF** (v3.3.0): 
  - Сканированные PDF (без текстового слоя) не поддерживаются — OCR пока недоступен
  - Защищённые паролем PDF должны быть разблокированы перед извлечением
  - Очень большие PDF (>100MB) могут не работать из-за ограничений памяти
  - Сложные макеты (многоколоночные, таблицы) извлекаются, но могут потребовать ручной проверки

### Совместимость с браузерами
- **Chrome/Edge/Brave/Arc**: Полностью поддерживается
- **Firefox**: Не поддерживается (использует другой API расширений)
- **Safari**: Не поддерживается (использует другой API расширений)

## 🔑 Получение API ключей

> **💡 Совет**: Вы можете использовать ClipAIble без API ключей! Автоматический режим работает мгновенно, используя локальные алгоритмы. API ключи нужны только для функций с ИИ (перевод, генерация резюме, режим AI Selector).
> 
> **💡 Новое в v3.2.0**: Piper TTS (офлайн) - Генерируйте аудио полностью офлайн с 50+ голосами на 9 языках, API ключи не требуются!
> 
> **💡 Исправлено в v3.2.1**: UI попапа обновляется корректно после генерации аудио, переключение голосов работает правильно для офлайн TTS.
> 
> **💡 Новое в v3.3.0**: Извлечение контента из PDF - Добавлена экспериментальная поддержка извлечения контента из PDF файлов. Предыдущее: Интеграция провайдера DeepSeek, оптимизации производительности, исправление помех Google Translate.

### OpenAI (модели GPT + Аудио)

1. Перейдите на [platform.openai.com](https://platform.openai.com/)
2. Зарегистрируйтесь или войдите
3. Перейдите в **API Keys** (левое меню) или напрямую на [platform.openai.com/api-keys](https://platform.openai.com/api-keys)
4. Нажмите **"Create new secret key"**
5. Скопируйте ключ (начинается с `sk-...`)
6. Добавьте оплату в **Settings → Billing** (требуется для использования API)

> **Примечание:** Ключ OpenAI требуется для экспорта в аудио (TTS). Другие форматы работают с любым провайдером.

### Google Gemini

1. Перейдите на [Google AI Studio](https://aistudio.google.com/)
2. Войдите с аккаунтом Google
3. Нажмите **"Get API key"** или перейдите на [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
4. Нажмите **"Create API key"**
5. Скопируйте ключ (начинается с `AIza...`)

> **Совет:** Gemini также включает функцию перевода текста на изображениях и Google Gemini 2.5 TTS (30 голосов). Для TTS можно использовать тот же ключ Gemini API или установить отдельный ключ Google TTS API. Требуется включение Generative Language API в Google Cloud Console.

### Anthropic Claude

1. Перейдите на [console.anthropic.com](https://console.anthropic.com/)
2. Зарегистрируйтесь или войдите
3. Перейдите в **API Keys**
4. Нажмите **"Create Key"**
5. Скопируйте ключ (начинается с `sk-ant-...`)
6. Добавьте кредиты в **Plans & Billing**

### DeepSeek

1. Перейдите на [platform.deepseek.com](https://platform.deepseek.com/)
2. Зарегистрируйтесь или войдите
3. Перейдите в **API Keys** или перейдите на [platform.deepseek.com/api_keys](https://platform.deepseek.com/api_keys)
4. Нажмите **"Create API key"**
5. Скопируйте ключ (начинается с `sk-...`)

> **Примечание:** DeepSeek предоставляет модели DeepSeek-V3.2 с режимами reasoning и без reasoning.

### ElevenLabs (Аудио)

1. Перейдите на [ElevenLabs](https://elevenlabs.io/)
2. Зарегистрируйтесь или войдите
3. Перейдите в **Profile** → **API Keys**
4. Создайте API ключ
5. Скопируйте ключ

> **Примечание:** ElevenLabs предоставляет высококачественный TTS с регулировкой скорости и выбором формата.

### Google Gemini 2.5 TTS (Аудио)

1. Перейдите на [Google AI Studio](https://aistudio.google.com/)
2. Войдите с аккаунтом Google
3. Нажмите **"Get API key"** или перейдите на [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
4. Нажмите **"Create API key"**
5. Скопируйте ключ (начинается с `AIza...`)
6. Включите **Generative Language API** в [Google Cloud Console](https://console.cloud.google.com/)
7. (Опционально) Включите биллинг, если требуется для вашей модели

> **Примечание:** Google Gemini 2.5 TTS. Можно использовать тот же ключ Gemini API или установить отдельный ключ Google TTS API.

### Qwen3-TTS-Flash (Аудио)

1. Перейдите на [Alibaba Cloud Model Studio](https://dashscope-intl.console.aliyun.com/)
2. Зарегистрируйтесь или войдите
3. Перейдите в **API Keys** или **Model Studio**
4. Создайте API ключ
5. Скопируйте ключ (начинается с `sk-...`)

> **Примечание:** Qwen3-TTS-Flash включает специальный русский голос (Alek).

### Respeecher (Аудио - Английский и Украинский)

1. Перейдите на [Respeecher Space](https://space.respeecher.com/)
2. Зарегистрируйтесь или войдите
3. Перейдите в **API Keys**
4. Создайте API ключ
5. Скопируйте ключ

> **Примечание:** Respeecher поддерживает английский и украинский языки со специальными украинскими голосами.

## 📊 Статистика и кэш

Нажмите **📊 Статистика** для просмотра:
- Общее количество сохранений, количество за этот месяц
- Разбивка по форматам (PDF, EPUB, FB2, Markdown, Аудио)
- Недавняя история со ссылками на оригинальные статьи (последние 50 сохранений)
  - Нажмите на ссылку для открытия оригинальной статьи
  - Нажмите кнопку ✕ для удаления отдельной записи истории
  - Показывает формат, домен, время обработки и дату
- Закэшированные домены для офлайн режима
- **Включить/Отключить статистику**: Переключатель сбора статистики
- **Очистить статистику**: Кнопка для сброса всей статистики
- **Очистить кэш**: Кнопка для удаления всех кэшированных селекторов
- Удаление отдельных доменов из кэша

## 📝 Генерация саммари

Создавайте подробные ИИ-саммари любой статьи или видео:

1. Перейдите на любую статью или видео YouTube/Vimeo
2. Нажмите кнопку **"Создать саммари"** в попапе
3. Саммари генерируется в фоне (можно закрыть попап)
4. Когда готово, саммари появляется с опциями:
   - **Копировать** в буфер обмена
   - **Скачать** как файл Markdown
   - **Развернуть/Свернуть** для просмотра полного текста
   - **Закрыть** для скрытия саммари

**Возможности:**
- Работает со статьями и видео YouTube/Vimeo
- Продолжает генерацию даже при закрытом попапе
- Подробные саммари с ключевыми идеями, концепциями, примерами и выводами
- Форматированный текст с заголовками, списками и ссылками
- Автоматически сохраняется — сохраняется до закрытия

**Примечание:** Генерация саммари отдельна от экспорта документа. Используйте для быстрого понимания содержимого без сохранения полного документа.

### Офлайн режим

ClipAIble кэширует сгенерированные ИИ селекторы по домену:
- **Второй визит = мгновенно** — без вызова API
- **Автоматическая инвалидация** — кэш очищается при неудачном извлечении
- **Ручное управление** — возможность удаления отдельных доменов
- **Независимые настройки**:
  - **Использовать кэшированные селекторы**: Пропустить анализ страницы, если кэш существует (быстрее)
  - **Включить кэширование**: Сохранять новые селекторы в кэш после извлечения
  - Обе настройки работают независимо для гибкого управления

## 🔧 Решение проблем

| Проблема | Решение |
|----------|---------|
| Пустое содержимое | Попробуйте режим **AI Selector** |
| Неверный API ключ | Проверьте формат ключа (sk-..., AIza..., sk-ant-...) |
| Отсутствуют изображения | Некоторые сайты блокируют cross-origin; маленькие изображения автоматически фильтруются |
| Медленное аудио | Длинные статьи разбиваются на части; следите за индикатором прогресса |
| Саммари не генерируется | Проверьте API ключ, убедитесь что содержимое страницы загружено, попробуйте снова |
| Таймаут генерации саммари | Очень длинные статьи могут занять до 45 минут; подождите или попробуйте с более коротким содержимым |
| Извлечение из PDF не работает | Проверьте, не защищён ли PDF паролем (сначала разблокируйте) или не является ли он сканированным (OCR пока не поддерживается). Попробуйте с более простыми PDF сначала. |
| Контент из PDF неполный | Сложные макеты (многоколоночные, таблицы) могут потребовать ручной проверки. Функция экспериментальная. |

## 📋 Разрешения

ClipAIble требует разрешения для:
- Чтения текущей страницы для извлечения содержимого
- Сохранения ваших настроек и сгенерированных файлов локально
- Выполнения API вызовов к провайдерам ИИ/TTS, которые вы настроили
- Доступа к сайтам только когда вы явно сохраняете их

**Примечание о безопасности:** Все API ключи зашифрованы и хранятся только локально. Ключи никогда не экспортируются и не передаются на какие-либо серверы, кроме провайдеров ИИ, которые вы настроили.

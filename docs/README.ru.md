# ClipAIble

Расширение для извлечения статей с помощью ИИ. Работает на любом сайте.

**Доступно в [Chrome Web Store](https://chromewebstore.google.com/detail/clipaible/khcklmlkddcaflkoonkkefjhdldcfolc)**

## Что оно делает

ClipAIble извлекает содержимое статей из веб-страниц и преобразует в различные форматы:
- PDF документы
- EPUB файлы
- FB2 файлы
- Markdown текст
- Аудио файлы

**Особые возможности:**
- **Поддержка YouTube/Vimeo**: Извлекает субтитры видео и создает статьи из них
- **Обработка PDF**: Работает с онлайн PDF и локальными PDF файлами
- **Перевод контента**: Перевод статей на 11 языков
- **Перевод изображений**: Перевод текста на изображениях с помощью ИИ
- **Генерация TLDR**: Создает краткие резюме внутри документов
- **Панель summary**: Показывает резюме статей в popup после обработки

## Как использовать

1. Нажмите на иконку ClipAIble в панели инструментов браузера
2. Откройте любую статью, видео на YouTube или PDF
3. Выберите нужный формат (PDF, EPUB, FB2, Markdown или Audio)
4. Нажмите сохранить

**Альтернативные способы сохранения:**
- Щелкните правой кнопкой мыши на любой веб-странице и используйте опции контекстного меню

**Для локальных PDF файлов**: В режимах ИИ вам будет предложено выбрать PDF файл из-за ограничений браузера.

## Настройки

### Режимы извлечения

- **AI Selector**: Рекомендуемый режим для большинства сайтов. Использует ИИ для поиска содержимого статьи.
- **Automatic**: Базовый режим, который работает без API ключей.
- **AI Extractor**: Альтернативный режим с ИИ (не рекомендуется для регулярного использования).

### Функции производительности

- **Кэширование селекторов**: Ускоряет обработку ранее посещенных сайтов путем повторного использования селекторов, изученных ИИ

### Форматы вывода

- **PDF**: Создает отформатированные документы с 4 готовыми стилями (Темный, Светлый, Сепия, Высокий контраст) и настраиваемыми шрифтами/цветами
- **EPUB**: Создает структурированные электронные книги для читалок вроде Kindle
- **FB2**: Создает структурированные электронные книги для PocketBook и других читалок
- **Markdown**: Сохраняет структуру статьи с заголовками и списками
- **Audio**: Преобразует текст в речь с использованием 6 различных TTS сервисов

### Перевод

Содержимое можно перевести на: английский, русский, украинский, немецкий, французский, испанский, итальянский, португальский, китайский, японский, корейский.

### Аудио

Аудио можно генерировать с помощью разных TTS провайдеров:
- OpenAI TTS
- ElevenLabs
- Google Gemini
- Qwen
- Respeecher (только английский и украинский)
- Piper (офлайн, API ключи не нужны)

## API ключи (опционально)

Для функций ИИ можно добавить API ключи от этих провайдеров:

### OpenAI
Получите ключ на [platform.openai.com/api-keys](https://platform.openai.com/api-keys)

### Google Gemini
Получите ключ на [aistudio.google.com/apikey](https://aistudio.google.com/apikey)

Для TTS включите [Generative Language API](https://console.cloud.google.com/apis/library/generativelanguage.googleapis.com) в Google Cloud Console

### Anthropic Claude
Получите ключ на [console.anthropic.com](https://console.anthropic.com/)

### DeepSeek
Получите ключ на [platform.deepseek.com/api_keys](https://platform.deepseek.com/api_keys)

### ElevenLabs
Получите ключ на [elevenlabs.io](https://elevenlabs.io/)

### Qwen
Получите ключ на [alibaba cloud dashscope](https://dashscope-intl.console.aliyun.com/)

### Respeecher
Получите ключ на [space.respeecher.com](https://space.respeecher.com/)

## Дополнительные возможности

- **Статистика**: Отслеживайте сохраненные статьи с историей и месячными счетчиками
- **Импорт/экспорт настроек**: Резервное копирование и восстановление ваших предпочтений
- **Интерфейс на 11 языках**: Переключение между языками без перезапуска
- **Отмена обработки**: Остановка любой операции в процессе
- **Безопасное хранение**: API ключи шифруются перед сохранением

## Разрешения

Расширению нужны эти разрешения для работы:
- Читать веб-страницы, которые вы посещаете
- Сохранять файлы на ваш компьютер
- Делать API вызовы к провайдерам ИИ (только когда вы используете эти функции)

**Безопасность**: Все API ключи шифруются перед сохранением в браузере.

# ClipAIble

Сохранение веб-статей в PDF, EPUB, FB2, Markdown или аудио.

[Chrome Web Store](https://chromewebstore.google.com/detail/clipaible/khcklmlkddcaflkoonkkefjhdldcfolc)

## Использование

1. Откройте статью, поддерживаемое видео или PDF.
2. Нажмите значок ClipAIble на панели инструментов Chrome.
3. Выберите формат и режим извлечения.
4. Нажмите **Сохранить**.

Сохранение также доступно в контекстном меню страницы. Для локальных PDF разрешите доступ к файлам в настройках расширения Chrome или выберите соответствующий файл по запросу. Если требуется выбор файла, оставьте popup расширения открытым.

Для веб-статей режим **Автоматический** использует локальные эвристики и доступные селекторы из кэша. **AI Selector** запрашивает у AI-сервиса CSS-селекторы, затем извлекает соответствующее содержимое страницы. **AI Extract** поручает сервису структурировать содержимое. Для PDF автоматический режим извлекает текстовый слой, а AI-режимы обрабатывают отрисованные страницы.

Для экспорта видео с YouTube и Vimeo нужны субтитры и API-ключ провайдера ИИ, выбранного для статей. Это касается и режима **Автоматический**.

В настройках доступны перевод текста и изображений, стили документа и оглавление. В окне расширения можно создать краткое содержание или ключевые тезисы. Для озвучки можно использовать настроенный сервис или скачать модель Piper либо Supertonic и синтезировать речь на компьютере.

Добавьте API-ключи для выбранных функций ИИ и озвучки. В резервную копию JSON входят настройки и пользовательские промпты. Статистику, историю и кэш селекторов можно включить по выбору. API-ключи в копию не входят. При импорте можно добавить недостающие записи истории и правила для новых сайтов или заменить выбранные разделы данными из копии. Подробнее в разделе [Резервные копии настроек](../README.md#back-up-settings).
